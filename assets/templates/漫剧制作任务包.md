# 漫剧制作任务包模板

适用不同题材、媒介与制作路线。

复制到具体项目使用。由执行者维护，不要求用户逐格填写。共 **5 份核心记录**，可放在同一文件中；这是策划、协作与验收记录，不是 ArcReel 可直接导入的接口格式。

配套：[完整制作手册](../../ARCREEL_PRODUCTION_PLAYBOOK.md)｜[一页执行卡](漫剧制作_一页执行卡.md)。执行时遵守当前工作区指令与用户授权。

## 使用方法：少填表，不漏决定

- **必记**：范围、基线版本、负责人、风险、预算与在途任务、采用来源、实际验收与交付。
- **每次动作**：在现有五份记录中引用 [阶段检查记录](阶段检查记录.json) 的 prepare/accept 与最新事实快照；按 [阶段准入与验收](../../references/production-gates.md) 填本阶段必需检查。保留逐目标采用版本、实际检查发现、组合一致性结论与依赖失效范围，禁止以生成成功填内容通过。
- **按需**：口型、声线、空间图、复杂动作等。不适用时写“不适用＋原因”，不以留空冒充通过。
- 已有决定引用原记录，不重复询问、抄写；用镜头 ID、素材 ID、任务 ID、版本号关联五份记录。
- 低风险可减少文书、复用条件匹配的小样，仍保留整集粗片/完整预演、授权费用核对、版本追溯与成片检查。
- 续做/局部修改引用已有批准的预演或成片及关口记录，只重开受影响部分，不重新填写所有前期表；改后的最终候选片仍做整体验证。
- **每集强钩子叙事契约**为阻断项：前 3 秒冲突、15–20 秒爆点、六个有效话语落点、静默不超 8 秒、后 1/3 有效反转及“压→爆”都要在粗片和成片兑现。
- **静帧/有限运动路线**可用静图、镜头运动与剪辑成片，不为走流程购买视频生成；仍验构图、节奏、衔接与实际导出。
- 技术计划越过本轮范围时报告冲突，不擅自执行；可以继续不受影响、无新增支出且已获授权的独立准备。

### 风险与问题分级

| 制作风险 | 判定参考 | 验证安排 |
|---|---|---|
| 低 | 同项目已验证路线、简单镜头、依赖清楚 | 可引用适用的技术小样；本集内容与最终结果仍检查 |
| 中 | 新角色/场景/声线、跨镜衔接或新的组合 | 验证对应新风险，再放行相关批次 |
| 高 | 多人互动、复杂连续动作、紧密口型、能力边界或成本不确定 | 拆解验证；能力、成本未查明前暂停相关付费任务 |

风险按具体内容判断，不按工具品牌或固定秒数判断；条件变化时重新评估。

- **阻断项**：影响关键理解、身份/台词、必要声画质量，或授权/费用不明。暂停受影响后续动作。
- **待修项**：有明确解决方法，且不影响当前阶段判断；注明责任人、截止关口及允许继续范围。
- **已接受局限**：有权决定的人针对具体版本明确接受，不把执行者自判写成用户认可。

“有条件通过”必须明确允许和禁止的下一步，不能带着阻断项进入相关计费生成或发布。

**多人协作**

- 同一项目/集同一时段指定一名正式写入负责人，统一提交剧本补丁、采用版本切换、素材导入与计费任务。同事可并行准备和审核。
- 修改前重读当前 revision/状态；冲突时先核对差异再合并，不覆盖他人新版本。
- 采用人工认领时如实记录，不宣称服务器已有自动锁；交接后旧负责人停止提交。
- 已批准基线及原始生成素材保留，实质变更产生新版本。

**中断后恢复**

- [ ] 认领当前任务，核对范围与基线，确认没有他人同时写入同一目标。
- [ ] 先查已有在途任务的提交、完成与扣费状态；断网/无文件不等于未提交。
- [ ] 核对已下载/已上传文件及版本，防止重复提交计费任务或重复切换采用项。
- [ ] 重算批准额度；未知扣费保留预留。
- [ ] 更新下一项安全动作与阻断原因，再继续。

## 核心记录 2：本集镜头与声音表——先把整集讲通

本集一句话意图：**这集希望观众看到、理解或感受到什么？** 同时写清“压力来源 → 压力升级 → 反转 → 本集兑现结果与代价”。

原文与改编取舍、观众信息揭示顺序：________。反转的表现形式服从题材，但每集都要有，并落在最终采用时长后 1/3。

固定空间/尺度/连续动作段落的母版与关键状态链（简图或现有文件链接；不适用写原因）：________。例如角色/主体尺寸、入口/楼梯/平台、摄影机可站位、动作轴线，以及“被埋→挣脱→站稳→取武器→攻击”分别由哪镜承担。

多集项目的状态交接：**本集进入状态 → 本集变化 → 离开状态/下一集继承项**（角色知识、关系、伤势/服装、道具、时间地点、伏笔等；不适用写明原因）：________。

### 本集强钩子叙事契约

| 指标 | 计划与证据 | G2 粗片结果 | G4 成片结果 |
|---|---|---|---|
| 0–3 秒激烈冲突＋第一处话语 | 冲突类型、时间、镜头/句 ID | | |
| 爆点间隔 ≤20 秒 | 全部时间点、类型、状态改变 | | |
| 有效话语落点 ≥6 | 句 ID、时点、说话者、类型、功能 | | |
| 连续静默 ≤8 秒 | 每段 in/out、目的、最长值 | | |
| 有效反转位于后 1/3 | 最终时长、2/3 边界、反转时点、依据/动机/后果 | | |
| 完成“压→爆” | 压力起点、升级、爆发、结果和代价 | | |

| 镜头 ID | 作用、因果与动机 | 入点→过程→出点；人物/物件位置、方向、动作阶段 | 摄影机机位/景别/运动目的；相邻接法与依据 | 声音/台词句 ID、文本、说话者与类型、情绪、路线 | 计划采用时长 / 实读时长 | 参考 ID / 风险与待验项 |
|---|---|---|---|---|---|---|
| | | | | | | |

填写约定：

- 相邻关系注明连续动作、反应/反打、时间省略或换场；只记相关位置、视线、手/道具及服装状态。
- 连续动作检查上一镜实际/拟采用出点与下一镜入点的空间、方向、速度/动作阶段、道具和尺度；有意省略写清观众可见的桥接线索，不要求画面像素相同。
- 运镜先有叙事目的，再从当前工具允许值中选；固定并非默认或错误。字段记录意图，实际视频仍需验是否移动、越轴及影响接点。
- 对白、心声、旁白、系统声分开；场内听众有歧义时写明。声线、关键读音与试听引用素材 ID。
- 首尾帧仅在确有动作连续需要且后端支持时使用；停顿、特写与合理省略可有叙事作用。
- 图生视频要保留动作起点；静帧路线则写实际采用的运动/切换，不假装包含未生成的角色动作。
- 复杂镜头按文末附表展开；简单镜头不再填长镜头卡。
- 四类时间分开：这里记**计划采用时长**；记录 4 记**请求时长**；记录 3 记**实际媒体时长与采用区间**。模型最短请求时长不是成片最短镜头时长。

**全集预演**：用草图/静帧、临时声音或明确的静音设计串成完整时间线，不要求先生成漂亮视频。版本与结论记入核心记录 5。

- [ ] 不靠设定说明书也能跟上本集核心体验；情节型检查目标、因果、动机和结果，其他类型按任务书检查。
- [ ] 有意保留的悬念/未知与无意造成的困惑已区分；观众仍能跟上本集核心体验。
- [ ] 位置与关键动作可解释；合理省略不等于所有进出都须单独拍。
- [ ] 关键状态变化在时间线上有承担镜头；连续动作的出入点闭合或有清楚的省略/转场依据。
- [ ] 台词、动作、反应与停顿放得下；不为凑请求时长拉长空白。
- [ ] 声音身份与节奏能判断；临时项明确标注，不冒充正式验证。
- [ ] 七条强钩子硬约束已按完整时间线核算，自动校验结果和人工审片结论均已登记。
- [ ] Series Bible、资产/变体引用与续集上下文包一致；未采用候选未写入正式连续性事实。
- [ ] 没有外部观众参与时记为内部自查，不写成观众测试。

**生成式画面放行记录（适用时）：** 单图身份/媒介 ________；同框空间/尺度 ________；高风险相邻候选图并排检查 ________；真实视频实际尾帧→下镜首帧/采用区间 ________；未通过的依赖链及停止条件 ________。四种证据不可互相替代；多段未验连续性的视频算批次，不因名为“小样”跳过关口。

## 核心记录 3：素材来源与采用映射——找到、复用、回退

| 素材 ID / 版本 | 文件绝对路径或团队稳定位置 / 哈希 | 真实来源、创建人/日期、任务 ID | 使用依据 / 参考与实际提示词或设置位置 | 实际规格、时长 / 源 in-out | 对应镜头/台词/轨道 / 时间线 in-out | 审核与采用状态 / 正式项目版本或导入结果 |
|---|---|---|---|---|---|---|
| | | | | | | |

- 真实来源可为手绘、拍摄、网页生成、Codex、本地模型或供应商；可确认的模型才填写，未知就写未知，界面默认标签不是来源证明。
- 原文、图片/角色参考、声音参考、音乐、音效、字体等的使用依据可引用共用说明。来源未知不等于已有授权，公开使用的未决项在发布前解决。
- 原始素材保留；采用处理记录参数或链接工程版本。正式采用素材记录哈希，不要求每张临时废稿建完整档案。
- 入出点用统一帧或高精度时间基准；剪辑/混音参数已有工程记录时不重复抄写。
- 保留可获得的对白、心声、环境/音效、音乐分轨及干声；只有原生混合轨就记“混合源”。分离/估算音轨不等于原始分轨。
- 技术状态、创作审核和采用状态分别识别；current 不代表审片通过，stale 不自动触发重生成。
- 费用只通过任务 ID 引用记录 4。不存密码、令牌或带鉴权参数的临时下载地址。
- 跨电脑交接检查依赖文件可访问，不只留下某台电脑路径。

## 核心记录 4：预算与任务账——提交前后都核对

### 每组批准的边界

- 批准 ID / 日期 / 批准人 / 原始记录：________
- 目标、供应商/档位、数量、额度来源与币种：________
- 本轮批准上限：________；返工/重试是否包含及边界：________
- 当前能力、价格来源与查询时间、实际提示词/参数预览位置：________
- 停止条件（超额、未知扣费、范围/路线改变、质量阻断等）：________

批准可覆盖小样或批次；同一批准范围内不反复打断用户。批准金额不等于允许任意换模型、增加目标或自动重试。小样如计费也须在批准范围内。

| 批准 ID / 本地提交记录 ID | 目标 / 供应商、档位与参数版本 | 请求单位/数量；当前单价及估价 | 供应商任务 ID / 提交状态、最后查询时间 | 已确认实际支出 | 未结算预留 | 任务结果 / 产物 ID / 质量结论引用 |
|---|---|---|---|---|---|---|
| | | | | | | |

**可新增承诺金额 = 本轮已批上限 − 已确认实际支出合计 − 未结算任务预留合计。**

- 在途及可能已扣费的未知任务保留预留；结算时实际支出**替换**该任务预留，不双重扣减。
- 不同币种/额度池分别核算；现金、订阅额度、本地算力/时间分别记，不混成“免费余额”。
- 提交前先落本地提交记录 ID，收到供应商任务 ID 后关联；超时先查原任务，不因没拿到文件就重发。
- 任务失败、内容不合格与未计费是三件事。未知不猜退款；重试另记并确认仍在批准边界内。
- 成本不明或超出可用额度时暂停相关提交，可继续无新增支出且不受影响的准备。
- 小样结论引用记录 5，成功任务数不代替可采用镜头数。

|---|---|---|---|---|---|
| | | | | | |

- 适用于剧本到交付的全流程；微小技术修正可合并登记，不把所有动作变成审批。
