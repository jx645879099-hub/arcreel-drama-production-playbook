# 漫剧制作：一页执行卡

开工、续做与交接时先看这页。

**先把前 3 秒冲突、爆点、六个话语落点、静默上限、后 1/3 反转和“压→爆”做进完整粗片，再用正式素材替换；不先攒漂亮片段，最后救火拼故事。**

这是快速入口。简单项目直接填写下方状态摘要，并引用现有素材和费用记录；复杂项目再展开 [五份核心记录任务包](漫剧制作任务包.md)，同一信息只维护一处。详细原则见 [制作手册](../../ARCREEL_PRODUCTION_PLAYBOOK.md)，执行时遵守当前工作区指令与用户授权。

## 开始前：六件事

- [ ] 明确项目、集数、本轮交付和不做的内容。
- [ ] 认准已批故事、时间线与素材版本，沿用既有决定。
- [ ] 确定唯一正式写入负责人；同事可并行准备，不同时覆盖版本或重复提交。
- [ ] 中断后先查在途任务、可能扣费与已有文件，不重跑一遍。
- [ ] 批准费用范围、可用额度和停止条件清楚。
- [ ] 下一动作在授权内；技术计划越界先报告，不为状态变绿自动扩集或重生成。

## 制作时：五个关口（与主手册编号一致）

| 关口 | 必须回答 | 通过后 |
|---|---|---|
| G0 开工基线 | 给谁看、采用何种路线？本轮范围、预算和责任是什么？ | 开始具体视听设计 |
| G1 故事与设定 | Series Bible、资产变体、续集上下文和本集叙事契约是否明确？空间/尺度/动作链是否可执行？ | 做全长预演 |
| G2 整集粗片 | 七条强钩子硬约束、必要声轨、人物去向、动作出入点、状态变化与节奏是否在完整时间线上成立？ | 制作路线所需的正式素材和风险样本 |
| G3 风险小样 | 单图、同框、相邻图及实际视频接点中的适用风险分别通过了吗？费用已核实吗？ | 获批范围内分批做，边做边替换粗片 |
| G4 成片交付 | 整集实际看过、适用声音听过吗？技术、来源、版本、费用对应吗？ | 交付具体版本；发布另获授权 |

### 每集强钩子契约

- [ ] 前 3 秒发生激烈冲突，第一处有效话语也在前 3 秒。
- [ ] 每 15–20 秒至少一个可感知爆点，任意相邻间隔不超过 20 秒。
- [ ] 有效话语落点不少于 6 个。
- [ ] 连续静默均不超过 8 秒。
- [ ] 至少一次有效反转，且发生点位于最终采用时长后 1/3。
- [ ] 反转有前置依据、人物动机、状态改变和即时后果。
- [ ] 本集已完成“压→爆”，释放和结果没有全部推到下一集。

**路线不同，叙事底线相同：** 静帧、有限运动、生成视频或混合制作都要在最终时间线兑现以上契约；静帧路线不为走流程购买视频生成。低风险可复用匹配的小样证据，仍保留本集完整预演与最终检查。

**动作链计费前再看一遍：** 上镜的出点与下镜的入点（位置、方向、速度/动作阶段、道具、相对尺寸）能接上或有明确省略依据吗？关键“倒地→站起”等状态变化在粗片里有镜头承担吗？候选图已按顺序并排看、实际视频接点已验吗？运镜选择有目的且实际画面兑现吗？任何一项待验，只放行独立且已获批的工作，不把多段未验视频称为“小样”一起提交。

续做或局部修改沿用已批准的预演/成片和关口记录，只重开受影响部分；最终候选片仍需整体验证，无需为更换两句心声重做全套前期。

## 发现问题：分类再动手

- **阻断项**：关键理解、身份/台词、必要质量不合格，或授权/费用不明——暂停受影响后续动作。
- **待修项**：不影响当前判断且有明确修法——记责任人、截止关口、允许继续范围。
- **已接受局限**：有权决定的人认可具体版本——保留记录，不伪装成完全解决。

先查故事、声音、引用、提示词与任务状态，再决定重生成。保留可用素材，但不因已付费硬留坏镜头。current/succeeded 不等于内容通过；stale 不自动要求重做。

## 每次计费前：算清一笔账
**可新增承诺 = 已批上限 − 已确认支出 − 在途/扣费未知预留。**

结算时实际支出替换预留，不双扣；不同币种/额度池分开。批准覆盖目标、路线/档位、数量、金额上限与重试边界。没文件不等于没扣费，超时先查原任务。范围、成本或路线实质变化再确认，同范围内不重复打断用户。

## 每次修改与结束时

- 明确基线、修改目标、保留项、下游影响；只重开受影响检查，留下新版本和回退位置。
- 局部修改触发整片重编码/全局混音时说明影响，不称非目标像素或音频完全不变。
- 实际检查、用户片段认可、用户整集认可分开；没做的写待验。
- 复杂项目展开五类记录：**状态卡 → 镜头声音表 → 素材采用映射 → 预算任务账 → 验收/变更/交付**；小项目可合并记录，但保留范围、费用、来源和实际验收证据。
- 候选、已验收、已交付、已发布分开；指定当前批准版本，交接核对依赖文件可访问，凭据不进资料包。

**用户通常只需确认方向、完整粗片、费用边界、最终成片。执行者负责制作、核查、记账与交接，不把所有技术细节变成用户的新问题。**
